# Decisions

## Data Cleaning
I handled missing values and inconsistent data in the dataset.

## Encoding
Categorical features were converted into numerical features using one-hot encoding.

## Feature Selection
Relevant student-related features were used for the prediction task.

## Models
I compared:
1. Logistic Regression
2. Decision Tree

## Model Selection
The Decision Tree performed better on my test data, so I selected it for the final prediction system.

## Prediction System
A user can enter student details such as CGPA, backlogs, projects, skills, internship and training status. The model then predicts whether the student is likely to be Placed or Not Placed.
